🌐 TranslateGemma Extension Test Page

📋 測試步驟：

  1. 確保您已經在插件中保存了 Hugging Face API Key
  2. 點擊瀏覽器工具欄中的 TranslateGemma 插件圖標
  3. 選擇「Translate to Traditional Chinese」測試英文翻譯
  4. 點擊「Restore Original」恢復原文
  5. 選擇「Translate to English」測試中文翻譯

English Content Section

Welcome to the TranslateGemma extension test page. This page contains various English text elements that should be translated to Traditional Chinese.

The extension uses Google's TranslateGemma 4B model, which is a state-of-the-art translation system supporting 55 languages.

Here are some common phrases:

  • Hello, how are you?
  • Thank you very much!
  • Where is the nearest restaurant?
  • I love programming and technology.
  • Artificial intelligence is changing the world.

繁體中文內容區塊

歡迎來到 TranslateGemma 插件測試頁面。這個頁面包含各種繁體中文文本元素，應該被翻譯成英文。

這個插件使用 Google 的 TranslateGemma 4B 模型，這是一個支援 55 種語言的最先進翻譯系統。

以下是一些常用短語：

  • 你好，你好嗎？
  • 非常感謝！
  • 最近的餐廳在哪裡？
  • 我熱愛編程和科技。
  • 人工智能正在改變世界。

Technical Information

Model: TranslateGemma 4B

API Provider: Hugging Face Inference API

Supported Directions:

  • English → Traditional Chinese (en → zh-TW)
  • Traditional Chinese → English (zh-TW → en)
